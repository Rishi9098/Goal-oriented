## The one-paragraph answer

Replace the placeholder Copilot with a **locally-served Qwen3-8B-class model (Apache 2.0)** acting purely as an **orchestrator and narrator** over what Northstar already owns: certified deterministic engines (Monte Carlo, optimizer, eligibility, insurance, dashboard) and versioned policy-fact tables. The model calls **read-only tools**, retrieves from a **small, curated, effective-dated corpus** (pgvector on the existing Postgres + BGE-M3 embeddings), and every reply passes a **deterministic grounding validator** that blocks any number or citation not traceable to this turn's tool outputs — making Engineering Constitution Rule 10 ("the AI computes nothing; it narrates what was already computed") *structurally enforced*, not merely instructed. **No fine-tuning in V1**; training is a later, evidence-gated QLoRA step (~$30/run on a rented GPU) using synthetic data generated by Northstar's own engines — never real user data.

## Why this is the right architecture (evidence, condensed)

- **Every successful production financial AI converges on this split** — Intuit (deterministic tax engine + LLM explanation), Morgan Stanley (curated-corpus-only RAG, staged rollout), FinGPT/academic consensus (facts in retrieval, not weights). The counter-example is BloombergGPT: ~$3M from-scratch training, beaten within a year by <$300 LoRA adaptations. *(02, 04)*
- **The model comparison was run honestly across 12 families** (Qwen, Llama, Mistral, Gemma, Phi, DeepSeek, GLM, Granite, InternLM, Yi, MiniCPM, LFM). Qwen3-8B/3.5-9B wins structurally: only family that is Apache-2.0 end-to-end **and** top-of-open-class at tool calling (BFCL evidence) **and** fits the 16 GB M4 (~5–7 GB at Q4) **and** covers the Hindi roadmap. Phi-4-mini = fast tier; Qwen3-32B/GLM-class = future hosted tier. *(01)*
- **Northstar's unfair advantage:** most teams must build the truth layer; Northstar's is already production-certified (330 tests, structured `why`/`what_was_used`/`confidence` on every recommendation, quarterly-versioned rates). The assistant is a narration layer over an existing, audited brain — and its best training/eval data generator is those same engines. *(02, 03, 09)*
- **The 16 GB M4 is sufficient for all of V1 development** (8–9B Q4 inference + embeddings + the app); it cannot meaningfully fine-tune 8B — which is fine, because V1 doesn't fine-tune. First GPU spend, if ever: a rented L4 by the hour. *(10)*

## What was decided

| Question | Decision |
|---|---|
| Model | **Qwen3-8B** now; Qwen3.5-9B evaluated head-to-head week one |
| Fine-tune now? | **No** — evidence-gated QLoRA at V2, format/voice only, synthetic data only |
| RAG or tools first? | **Tools first** (they answer ~80% of real questions from certified engines), minimal RAG alongside |
| Safety spine | Read-only tools, auth injected server-side, deterministic grounding validator, kill switch to the existing rule-based fallback |
| Rollout | Dogfood → default-on with counsel-reviewed "education, not advice" framing → writes only at V4 with per-action confirmation + audit |

## Key risks & open items (named, not hidden)

1. **Legal review required** before default-on: SEBI investment-advice boundary wording *(08 §5 — flagged, not resolved here)*.
2. **`calculate_tax` engine does not exist** — versioned tax data does; the computation engine is future deterministic-engine work, and the assistant must decline tax math until it ships *(06 §4)*.
3. **Fast-moving facts** marked throughout: exact current Qwen checkpoint/licenses, GPU prices, M4 tokens/s — re-verify at implementation time; several judgments rest on Jan-2026 training knowledge, all marked.
4. **Prompt injection cannot be eliminated**, only bounded — V1's worst case is deliberately capped at "badly phrased reply about the user's own data" *(08 §2)*.
5. Estate planning & HUF procedures: no reliable corpus → explicit refusal list, per Product Principle #8 *(03 §7)*.

## The strategic point

A GPT-4o-dependent competitor cannot say *"your financial life never leaves your infrastructure."* Northstar, with a local model narrating locally-computed, versioned, audited truth, can — and the certification discipline this project already practices is precisely what makes that claim credible.
