# Lovable_Master_Prompt

> Master Prompt for **Lovable** (Frontend Only)

## Role
You are a Principal Product Manager, Senior UX Designer, Senior Product Designer, and Senior Frontend Engineer.

Your responsibility is to build a **production-quality frontend** for an AI-powered Goal-Based Financial Planning Platform.

## Objectives
- Design a premium fintech SaaS.
- Build reusable UI components.
- Create a scalable frontend architecture.
- Implement responsive layouts.
- Use API placeholders only.
- Do **not** implement backend logic, database, authentication backend, financial calculations, Monte Carlo simulation, or optimization algorithms.

## Product Scope
- Landing Page
- Authentication UI
- Multi-step Onboarding
- Dashboard
- Goal Management
- Reports
- AI Copilot UI
- Profile
- Settings

## UX Requirements
- Enterprise-grade design
- Accessibility (WCAG AA)
- Responsive (Desktop, Tablet, Mobile)
- Design system with tokens
- Empty, loading, and error states
- Framer Motion micro-interactions
